# ls-folio

Сайт-портфолио Lana Svitla. Статические страницы, без сборщика: HTML, CSS и
немного ванильного JS. Публикуется через GitHub Pages.

## Структура

```
index.html            главная со списком работ
about.html            обо мне
process.html          процесс работы
contacts.html         контакты
work/<slug>/          страницы кейсов
partials/             компоненты: шапка, подвал, список соцсетей
tools/                скрипты сборки и проверки
assets/               стили, скрипты, шрифтовые иконки, картинки, CV
notes/                решения по проекту и брифы
```

## Компоненты

Шапка и подвал не копируются руками. Они лежат в `partials/`, а страницы
получают их из `tools/pages.json` через рендерер. Правится партиал — прогоняется
рендерер — обновляются все страницы сразу.

```bash
python3 tools/render_partials.py           # разложить компоненты по страницам
python3 tools/render_partials.py --check    # проверить, ничего не собирая
```

## Проверки перед публикацией

```bash
python3 tools/render_partials.py --check   # компоненты на страницах свежие
python3 tools/typography.py --check        # висячие предлоги, «ё», длинное тире
python3 tools/refresh_cv.py                # подтянуть актуальные CV из Google Docs
```

## Картинки

Все изображения — WebP, размер под удвоенный слот для Retina, кадрирование
делается в самом файле, а не через CSS.

```bash
cwebp -q 80 -resize <ширина> 0 исходник.jpg -o результат.webp
```

Неиспользуемые исходники лежат в `assets/_archive/` и в репозиторий не входят.
