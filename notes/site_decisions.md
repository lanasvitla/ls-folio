## Архитектура

Статический сайт, общие блоки собираются из партиалов:

```
partials/site-header.html   компонент
partials/site-footer.html   компонент
partials/social-links.html  вложенный компонент, подключается через {{> social-links}}
tools/pages.json            манифест страниц и значений
tools/render_partials.py    сборщик
```

Сборка: `python3 tools/render_partials.py` (проверка без записи — `--check`).
Правки общих блоков делать **только в партиалах**, не в собранных страницах.

Любой блок, встречающийся больше чем на одной странице, обязан быть компонентом.

## Анимация появления контента

Единое правило для **всех страниц** сайта: блоки выезжают **справа налево** с
затуханием, каскадом — каждый следующий на 110 мс позже предыдущего.

- Реализация: класс `.reveal` + `IntersectionObserver` в `assets/js/main.js`.
- `--i` — позиция элемента **внутри пачки, появляющейся одновременно**, а не в
  документе. Иначе одиночный блок, доскроленный до экрана, ждал бы чужую задержку.
- Длительность 0.8s, кривая `--ease`.
- При системной настройке «уменьшить движение» сдвиг и задержки отключаются.
- Новый блок анимируется автоматически — достаточно повесить на него `reveal`.

## Типографика (обязательна для всего русского текста)

- Короткие предлоги/союзы не висят в конце строки — склеивать `&nbsp;`.
- Буква «ё» не используется, пишем «е».
- Тире среднее `–`, не длинное `—`.

Правится **скриптом, не руками**: `python3 tools/typography.py`
(проверка без записи — `--check`). Скрипт трогает только текст между тегами,
не заходит в атрибуты, `<script>`, `<style>` и `<svg>`, идемпотентен.

Порядок при правке общих блоков: сначала `typography.py` (включая партиалы),
затем `render_partials.py`.

## Особенности, которые легко сломать

- **Футер закреплён** (`position: fixed`) и открывается из-под контента. Поверх него
  лежит непрозрачный слой `.page`, включающий хедер, — без него футер просвечивает
  сквозь прозрачный хедер вверху страницы.
- Если футер выше экрана (короткие телефоны), закрепление автоматически отключается
  классом `no-footer-reveal` — порог считается в `main.js`.
- На странице контактов футера нет намеренно (как в эталоне), только копирайт.
- Плашка хедера имеет свой еле заметный фон **всегда**, а не только при скролле.
